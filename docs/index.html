Gemini-Based AI Assistant with Database of KITS

An AI-powered voice assistant for accessing KITS computer and machine information.

View Source Code

About the Project

KITS Helper is a voice-based AI assistant that uses Google Gemini and an Excel-based knowledge database to provide information about computers, machines, and equipment in KITS.

Key Features

  • Voice input
  • Google Gemini AI integration
  • Excel-based knowledge database
  • Database search
  • Text-to-speech responses
  • PC and machine information

System Architecture

User Voice Input ↓ Speech Recognition ↓ Database Search ↓ Excel Knowledge Base ↓ Google Gemini AI ↓ AI Response ↓ Text-to-Speech ↓ User

Technologies Used

Python, Google Gemini AI, Speech Recognition, pyttsx3, OpenPyXL, Excel, and Linux/ALSA Audio.

Database Structure

The system uses a main database.xlsx file and multiple machine-specific Excel databases stored in the Karunya_Machine_Knowledge_Base_Excel folder.

Sample Questions

  • What computers are available in the KITS lab?
  • How many PCs do we have?
  • What are the specifications of PC 1?
  • What processor does PC 5 have?
  • What is the RAM capacity of PC 10?
  • Which machines are available in the studio?

Project Limitations

  • Requires a Gemini API key.
  • Requires an internet connection for Gemini.
  • Currently designed primarily for Linux.
  • Requires a working microphone.
  • Information depends on the Excel knowledge base.

Future Improvements

  • Web-based interface
  • Windows support
  • Improved natural-language database search
  • Offline speech recognition
  • Conversation history
